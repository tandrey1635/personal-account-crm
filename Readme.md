# Корпоративный портал «Личный кабинет CRM»
Сайт внутренней CRM-системы для управления организациями, мероприятиями и отчетностью на чистом HTML5/SASS с адаптивным дизайном.


## 🛠 Технологический стек

### Frontend
- **HTML5** — семантическая верстка, БЭМ-методология
- **SASS/SCSS** — модульная структура, сброс стилей, медиа-запросы
- **JavaScript** — работа с DOM, обработка событий


## 🎯 Ключевые функции

### UI/UX элементы
- Адаптивное бургер-меню для мобильных устройств
- Адаптивные карточки статистики (поля, урожай, погода, сотрудники)
- Адаптивные таблицы с рейтингом организаций
- Выпадающие списки (селекты)
- Блоки с иконками и графиками
- Формы для создания проверок и документов


## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует навыки разработки сложных интерфейсов для внутренних CRM-систем с адаптивом, таблицами и формами.**
